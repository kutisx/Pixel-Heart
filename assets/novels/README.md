# Изображения новелл

Hero-карусель ждёт четыре файла:

```
assets/novels/doki.png    → Doki Doki
assets/novels/saya.png    → Saya no Uta
assets/novels/nine.png    → 9 Rip
assets/novels/va11.png    → VA-11 HALL-A
```

## Что уже лежит в репозитории

В папке лежат четыре **временные абстрактные заглушки** (1200 × 800 px),
сгенерированные для учебной сборки: тёмный градиент, свечение, пиксельная
сетка и звёзды в цветах соответствующей палитры. Это не арт игр и не кадры
из них — просто фон, чтобы карусель выглядела собранной.

## Что делать команде

1. Положить свои изображения по тем же путям и с теми же именами
   (рекомендуемый размер — 1600 × 1000 px, соотношение 16:10, PNG или WebP).
2. Не менять имена файлов — пути зашиты в `js/data.js` (`NOVELS[].image`).
3. Если файла нет, сайт не ломается: `js/hero.js` показывает аккуратный
   SVG-плейсхолдер с названием новеллы и подсказкой «Положите файл: …».
4. Проверить права на изображения и указать источник в README и в подвале
   сайта. Сейчас в подвале стоит учебная оговорка: проект не выдаёт себя
   за официальные сайты игр, права принадлежат правообладателям.
